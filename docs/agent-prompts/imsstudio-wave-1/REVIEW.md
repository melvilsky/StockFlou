## Подтверждённые замечания

### P1 Контекст Editorial может перейти между материалами

В /Volumes/orico/Projects/StockFlou/lib/features/generation/presentation/generation_screen.dart:778 после ответа API повторно читается общий editorialStateProvider. Выбор другого материала синхронизирует этот provider в том же файле около строки 663. Поэтому запуск на A и переход к B могут сохранить в A режим, город, страну и дату B. Идентификатор результата теперь фиксирован правильно, но содержимое Editorial остаётся привязанным к открытому инспектору.

Дополнительно EXIF/геокодирование исходного материала обновляют общий provider после await около строк 739–749. В пакетной обработке контекст и режим читаются внутри отложенного работника, поэтому поздние элементы серии могут получить уже изменённые настройки.

Подтверждение: просмотр цепочки вызовов и исходного кода. Настоящий AI-запрос не выполнялся. Это оставшаяся проблема полного сценария, а не доказанная новая регрессия функции тегов. Вторая группа выделяет её в самостоятельное задание с управляемыми асинхронными тестами.

### P2 Конфликт CSV не исключает все строки

В /Volumes/orico/Projects/StockFlou/lib/core/services/csv_metadata_service.dart:174 повторные цели считаются только среди строк, которые уже прошли проверку значений.

Воспроизведено на текущем коде:

```csv
Filename,Title,IsEditorial
photo.jpg,first,true
photo.jpg,second,invalid
```

Обе записи однозначно относятся к одному материалу. Получается одно применимое изменение и одна ошибка boolean. По согласованному правилу конфликта не должна применяться ни одна из двух записей.

### P2 Невозможная дата молча исправляется

В /Volumes/orico/Projects/StockFlou/lib/core/services/csv_metadata_service.dart:265 используется DateTime.tryParse без проверки календарных границ.

Воспроизведено: CSV с EditorialDate=2026-02-31 формирует применимое изменение с датой 2026-03-03, без сообщения об ошибке. Нужна строгая проверка до сохранения. Это особенно существенно для редакционных материалов.

### P2 Непустой Path из пробелов разрешает поиск по имени

В /Volumes/orico/Projects/StockFlou/lib/core/services/csv_metadata_service.dart:210 условие path.trim().isNotEmpty считает строку из пробелов отсутствующим Path.

Воспроизведено: Path из трёх пробелов и совпадающий Filename дают применимое изменение. По договорённости только отсутствующий или действительно пустой Path допускает поиск по имени; непустое неверное значение должно быть ошибкой. Пути нельзя молча исправлять.

### P2 Частичный импорт не обновляет состояние каталога

В /Volumes/orico/Projects/StockFlou/lib/features/generation/presentation/widgets/csv_import_preview_dialog.dart:107 запись идёт напрямую в DatabaseHelper. После частичного успеха кнопка «Закрыть» возвращает false около строки 227. Родитель обновляет filesProvider только при true: /Volumes/orico/Projects/StockFlou/lib/features/generation/presentation/generation_screen.dart:199.

Таким образом, успешно записанные строки уже есть в базе, а наблюдаемое состояние каталога остаётся прежним до отдельного обновления. Подтверждено по коду; отдельный тест этого сценария в проверке не запускался. Исправление можно полностью сделать в диалоге, сохранив его bool-контракт и не меняя родительский экран.
